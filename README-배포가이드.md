# go견적 홈페이지 — 배포 가이드

## 1. 도메인 / 호스팅
- 확정 도메인: **https://www.godampro.kr/** (canonical·OG·sitemap·robots 전부 이 주소로 반영 완료)
- 정적 파일이라 Netlify·Vercel·GitHub Pages 어디든 동일하게 동작합니다.
- 폴더 전체를 드래그앤드롭 → 도메인 연결 → 끝.

## 2. 배포 전 반드시 채울 자리 (검색해서 교체)
| 찾기 | 바꾸기 | 위치 |
|---|---|---|
| `[유선번호 입력]` / `tel:000-0000-0000` | 실제 유선 전화번호 | index.html (푸터 + 모바일 하단 전화 버튼) |
| `[신고 완료 후 입력]` | 통신판매업 신고번호 | index.html 푸터 |
| `[이메일 주소]` | 개인정보 보호책임자 이메일 | privacy.html |

※ 이 3개는 **토스페이먼츠 가맹점 심사 통과 필수 항목**입니다. 특히 유선번호·통신판매업 신고번호가 없으면 심사에서 막힙니다.

## 4. SEO 등록 (배포 당일)
1. 네이버 서치어드바이저 → 사이트 등록 → 사이트맵 제출: `https://www.godampro.kr/sitemap.xml`
2. 구글 서치 콘솔 → 속성 추가 → Sitemaps 제출
3. 유튜브 타일킹고대표 채널 설명·고정댓글에 홈페이지 링크 추가
